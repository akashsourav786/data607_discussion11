# DATA 607 Discussion 11: Steam's Interactive Recommender

Research report by Akash Sourav examining Steam's Interactive Recommender through customer and organization scenario design, public documentation, and carefully labeled inference.

## Files

- `discussion11.qmd`: required Quarto source notebook.
- `discussion11.md`: generated Markdown, readable directly on GitHub.
- `discussion11.html`: self-contained rendered report.
- `discussion-post.txt`: accompanying course discussion post.

## Render

Install [Quarto](https://quarto.org/docs/get-started/), then run from this folder:

```bash
quarto render discussion11.qmd --to all
```

No R or Python code runs in the notebook. No packages, account credentials, private PDFs, or datasets are required to render it. The source contains its references.

## Research scope

The report answers the three scenario-design questions separately for players and Valve's organizational stakeholders, reconstructs the documented recommendation approach, and proposes four prioritized improvements with evaluation measures. The public recommender redirected to sign-in during research. Interface features are therefore attributed to Valve's documentation, rather than presented as personally tested controls. Technical announcements from 2019 are explicitly identified as historical.
